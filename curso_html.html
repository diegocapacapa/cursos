Introdução ao HTML

O esqueleto de toda página da web.

HTML significa HyperText Markup Language — não é uma linguagem de programação, é uma linguagem de marcação: ela descreve a estrutura de uma página usando tags (elementos entre < e >), sem lógica, sem cálculos, sem variáveis. O navegador lê essas tags e desenha a página na tela.

primeira_pagina.html 
<h1>Olá, mundo!</h1>
<p>Esta é minha primeira página em HTML.</p>
Dica: A maioria das tags vem em pares: uma de abertura <p> e uma de fechamento </p>. O conteúdo fica entre as duas.
Aprofundando: A maior parte do que você vê na internet — sites de notícias, redes sociais, lojas — usa HTML para estruturar o conteúdo. CSS cuida da aparência e JavaScript do comportamento; você vai ver os três juntos ao longo do curso.

Mais um exemplo

mais_tags.html 
<h2>Sobre mim</h2>
<p>Estou aprendendo <strong>HTML</strong> agora.</p>
<p>Depois vou aprender <em>CSS</em> e JavaScript.</p>

01

Estrutura básica de uma página

O esqueleto obrigatório de todo arquivo .html.

Todo documento HTML segue uma estrutura básica: <!DOCTYPE html> avisa o navegador que a página usa o HTML5 atual; <html> envolve tudo; <head> guarda informações que não aparecem na tela (como o título da aba); e <body> guarda tudo que é visível.

estrutura.html 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Minha página</title>
</head>
<body>
  <h1>Bem-vindo!</h1>
  <p>Este é o conteúdo visível da página.</p>
</body>
</html>
Dica: O atributo lang="pt-BR" na tag <html> avisa leitores de tela e buscadores qual o idioma da página.
Aprofundando: A tag <meta charset="UTF-8"> garante que acentos e caracteres especiais (como ç, ã, á) apareçam corretamente — sem ela, o navegador pode exibir símbolos estranhos no lugar deles.

Mais um exemplo

charset.html 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Acentuação</title>
</head>
<body>
  <p>Programação, coração, informação — tudo certo com UTF-8.</p>
</body>
</html>

02

Textos e títulos

Organizando o conteúdo escrito de uma página.

HTML tem seis níveis de título, de <h1> (o mais importante) até <h6> (o menos importante), e a tag <p> para parágrafos. Use os títulos para criar uma hierarquia lógica no conteúdo, como um sumário.

titulos.html 
<h1>Receita de bolo</h1>
<h2>Ingredientes</h2>
<p>Farinha, ovos, açúcar e fermento.</p>
<h2>Modo de preparo</h2>
<p>Misture tudo e leve ao forno por 40 minutos.</p>
Dica: Use apenas um <h1> por página — ele representa o assunto principal, como o título de um livro.
Aprofundando: Dentro de um parágrafo, você pode destacar palavras com <strong> (importância, geralmente em negrito) ou <em> (ênfase, geralmente em itálico). Existe também <br>, que quebra a linha sem criar um novo parágrafo.

Mais um exemplo

destaques.html 
<p>Este curso é <strong>gratuito</strong> e você pode <em>praticar</em> a qualquer hora.<br>
Comece agora mesmo!</p>
TESTE RÁPIDO 1/2

🧩 Desafio prático

03

Comentários e boas práticas

Anotações que o navegador ignora, mas que ajudam quem lê o código.

Comentários em HTML ficam entre <!-- e --> e são completamente ignorados pelo navegador — servem só para deixar anotações para você mesmo ou para outras pessoas que forem ler o código depois.

comentarios.html 
<!-- Cabeçalho da página -->
<h1>Minha loja</h1>

<!-- TODO: adicionar o menu de navegação aqui -->

<p>Bem-vindo à loja!</p>
Dica: Indentar o código (usar espaços para mostrar o que está "dentro" do quê) não é obrigatório para o navegador, mas torna o código muito mais fácil de ler.
Aprofundando: É uma boa prática usar letras minúsculas nos nomes das tags (<p>, não <P>) e sempre fechar as tags que precisam ser fechadas — mesmo que o navegador seja tolerante com erros, o código fica mais previsível e fácil de manter.

Mais um exemplo

boas_praticas.html 
<!-- bom: minúsculo, indentado e fechado corretamente -->
<div>
  <p>Texto organizado.</p>
</div>

04

Links

Conectando páginas — a base da "teia" (web).

A tag <a> (de "anchor") cria um link. O endereço de destino vai no atributo href. Links podem apontar para outros sites, outras páginas do mesmo site, ou até para uma seção dentro da própria página.

links.html 
<a href="https://www.python.org">Site oficial do Python</a>
<br>
<a href="https://www.python.org" target="_blank">Abrir em nova aba</a>
Dica: O atributo target="_blank" abre o link em uma nova aba, em vez de navegar para longe da página atual.
Aprofundando: Links também podem apontar para um lugar dentro da mesma página usando #id-do-elemento, e para o e-mail de alguém usando mailto: — muito comum em páginas de contato.

Mais um exemplo

links_especiais.html 
<a href="#secao-contato">Ir para a seção de contato</a>

<a href="mailto:contato@exemplo.com">Enviar e-mail</a>

<h2 id="secao-contato">Contato</h2>
<p>Fale com a gente!</p>
TESTE RÁPIDO 1/2

Qual atributo define para onde um link aponta?

05

Imagens

Incluindo fotos e ilustrações na página.

A tag <img> insere uma imagem. Ela não tem tag de fechamento e usa o atributo src para indicar o arquivo (ou endereço) da imagem, e alt para um texto alternativo — essencial para acessibilidade e para quando a imagem não carrega.

imagens.html 
<img src="https://picsum.photos/seed/curso/320/180" alt="Paisagem ilustrativa" width="320">
<p>Uma imagem de exemplo carregada da internet.</p>
Dica: O atributo width (e/ou height) controla o tamanho da imagem. Definir só um dos dois mantém a proporção original.
Aprofundando: Leitores de tela usados por pessoas com deficiência visual leem o texto do alt em voz alta — por isso ele deve descrever o conteúdo da imagem, não repetir algo como "imagem" ou ficar em branco.

Mais um exemplo

alt_acessivel.html 
<!-- ruim: alt vazio ou genérico -->
<img src="grafico.png" alt="imagem">

<!-- bom: alt descritivo -->
<img src="grafico.png" alt="Gráfico de vendas crescendo de janeiro a junho">

06

Listas

Organizando itens em sequência ou sem ordem específica.

Existem dois tipos principais de lista: <ul> (lista não-ordenada, com marcadores) e <ol> (lista ordenada, numerada). Em ambas, cada item fica dentro de uma tag <li>.

listas.html 
<h2>Ingredientes</h2>
<ul>
  <li>Farinha</li>
  <li>Ovos</li>
  <li>Açúcar</li>
</ul>

<h2>Modo de preparo</h2>
<ol>
  <li>Misture os ingredientes</li>
  <li>Despeje na forma</li>
  <li>Leve ao forno por 40 minutos</li>
</ol>
Dica: Listas podem ser aninhadas: coloque uma <ul> inteira dentro de um <li> para criar sublistas.
Aprofundando: Existe um terceiro tipo, menos comum: a lista de definição (<dl>), que combina um termo (<dt>) com sua definição (<dd>) — útil para glossários.

Mais um exemplo

lista_definicao.html 
<dl>
  <dt>HTML</dt>
  <dd>Linguagem de marcação usada para estruturar páginas web.</dd>
  <dt>CSS</dt>
  <dd>Linguagem usada para estilizar a aparência das páginas.</dd>
</dl>

07

Tabelas

Organizando dados em linhas e colunas.

Uma tabela é montada com <table>, cada linha é uma <tr> (table row), e dentro de cada linha ficam as células: <th> para cabeçalho (em negrito por padrão) e <td> para dados normais.

tabela.html 
<table border="1">
  <tr>
    <th>Produto</th>
    <th>Preço</th>
  </tr>
  <tr>
    <td>Caderno</td>
    <td>R$ 15,00</td>
  </tr>
  <tr>
    <td>Caneta</td>
    <td>R$ 3,00</td>
  </tr>
</table>
Dica: O atributo border="1" é só para visualizar rapidamente as linhas durante o aprendizado — em projetos reais, as bordas são definidas com CSS.
Aprofundando: Tabelas grandes costumam ser divididas em três partes: <thead> (cabeçalho), <tbody> (corpo com os dados) e <tfoot> (rodapé, como um total) — isso ajuda tanto na organização quanto na acessibilidade.

Mais um exemplo

tabela_estruturada.html 
<table border="1">
  <thead>
    <tr><th>Item</th><th>Qtd.</th></tr>
  </thead>
  <tbody>
    <tr><td>Maçã</td><td>3</td></tr>
    <tr><td>Banana</td><td>5</td></tr>
  </tbody>
  <tfoot>
    <tr><td>Total</td><td>8</td></tr>
  </tfoot>
</table>

08

Divs e Spans

Blocos genéricos para organizar e agrupar conteúdo.

<div> e <span> não têm significado próprio — são "caixas" genéricas usadas para agrupar outros elementos, geralmente para aplicar estilo (CSS) ou comportamento (JavaScript) a um grupo. A diferença: <div> é um bloco (ocupa a linha inteira), <span> é embutido no meio do texto (inline).

divs_spans.html 
<div>
  <h2>Cartão de produto</h2>
  <p>Preço: <span>R$ 49,90</span></p>
</div>
Dica: Só use <div>/<span> quando nenhuma tag mais específica se encaixar — no próximo capítulo você vai ver tags com significado próprio, como <header> e <nav>.
Aprofundando: Como <div> e <span> não têm estilo próprio, eles são a base para praticamente qualquer layout feito com CSS — é comum ver várias <div> aninhadas organizando seções inteiras de uma página.

Mais um exemplo

divs_aninhadas.html 
<div>
  <div>
    <h3>Card 1</h3>
    <p>Conteúdo do primeiro card.</p>
  </div>
  <div>
    <h3>Card 2</h3>
    <p>Conteúdo do segundo card.</p>
  </div>
</div>

09

Formulários

Coletando informações digitadas pelo visitante.

A tag <form> agrupa campos de entrada de dados, como caixas de texto e botões. Cada campo geralmente vem acompanhado de uma <label>, que descreve o que aquele campo espera — importante tanto para clareza quanto para acessibilidade.

formulario.html 
<form>
  <label for="nome">Nome:</label>
  <input type="text" id="nome" name="nome">
  <br>
  <label for="email">E-mail:</label>
  <input type="email" id="email" name="email">
  <br>
  <button type="submit">Enviar</button>
</form>
Dica: O atributo for da <label> deve ser igual ao id do campo — isso faz o navegador focar no campo quando você clica no texto da label.
Aprofundando: Sem um servidor por trás, o botão "Enviar" deste capítulo não manda os dados para lugar nenhum de verdade — em um site real, o atributo action do <form> apontaria para onde os dados devem ser enviados, e isso normalmente é tratado com código de back-end.

Mais um exemplo

form_completo.html 
<form>
  <label for="cidade">Cidade:</label>
  <select id="cidade" name="cidade">
    <option value="sp">São Paulo</option>
    <option value="rj">Rio de Janeiro</option>
  </select>
  <br>
  <label for="msg">Mensagem:</label>
  <br>
  <textarea id="msg" name="msg" rows="3"></textarea>
  <br>
  <button type="submit">Enviar</button>
</form>

10

Botões e inputs

Os diferentes tipos de campo disponíveis em um formulário.

A tag <input> muda de comportamento dependendo do atributo type: texto simples, senha (que esconde os caracteres), caixa de marcação (checkbox), botão de opção (radio), data, e muitos outros.

tipos_input.html 
<label>Senha: <input type="password"></label>
<br>
<label><input type="checkbox"> Aceito os termos</label>
<br>
<label><input type="radio" name="plano"> Plano mensal</label>
<label><input type="radio" name="plano"> Plano anual</label>
<br>
<label>Data de nascimento: <input type="date"></label>
Dica: Botões do tipo radio com o mesmo name formam um grupo — só é possível marcar um deles por vez.
Aprofundando: Existe também type="range" (um controle deslizante) e type="color" (um seletor de cor) — o navegador desenha a interface automaticamente, sem precisar de nenhum código extra.

Mais um exemplo

inputs_avancados.html 
<label>Volume: <input type="range" min="0" max="100"></label>
<br>
<label>Cor favorita: <input type="color"></label>

11

Atributos globais (class, id, style)

Marcando elementos para estilizar ou identificar de forma única.

Quase toda tag HTML aceita os atributos class e id. id identifica um elemento de forma única na página (não pode repetir); class agrupa vários elementos que compartilham um estilo ou comportamento (pode repetir à vontade). O atributo style aplica CSS diretamente na tag.

atributos.html 
<p id="destaque" class="aviso">Este parágrafo tem um id único.</p>
<p class="aviso">Este compartilha a classe "aviso" com o de cima.</p>
<p style="color: blue;">Este usa estilo direto na tag.</p>
Dica: Use id para um elemento específico que você vai referenciar (por exemplo, um link interno com #id), e class para estilos reutilizáveis em vários elementos.
Aprofundando: É considerada boa prática evitar o atributo style direto na tag sempre que possível, preferindo classes e um arquivo CSS separado — isso mantém o estilo organizado em um só lugar, em vez de espalhado pelo HTML.

Mais um exemplo

preferindo_classes.html 
<!-- menos organizado -->
<p style="color: red; font-weight: bold;">Aviso importante</p>

<!-- mais organizado: o estilo fica definido em um CSS à parte -->
<p class="aviso-importante">Aviso importante</p>

12

Iframes, vídeo e áudio

Incorporando conteúdo de fora e mídia na página.

A tag <iframe> incorpora outra página inteira dentro da sua (muito usada para vídeos do YouTube, mapas, etc). Já <video> e <audio> tocam arquivos de mídia diretamente, com um player nativo do navegador.

midia.html 
<video controls width="280">
  <source src="video.mp4" type="video/mp4">
  Seu navegador não suporta vídeo.
</video>

<audio controls>
  <source src="som.mp3" type="audio/mpeg">
  Seu navegador não suporta áudio.
</audio>
Dica: O atributo controls mostra os botões de play, pausa e volume — sem ele, o vídeo/áudio não teria nenhum controle visível para o usuário.
Aprofundando: O texto dentro de <video> ou <audio> (como "Seu navegador não suporta vídeo") só aparece em navegadores muito antigos que não reconhecem essas tags — é um conteúdo alternativo (fallback).

Mais um exemplo

iframe_exemplo.html 
<iframe src="https://exemplo.com/mapa" width="300" height="200" title="Mapa incorporado"></iframe>

Semântica (header, nav, main, footer)

Tags que descrevem o significado das partes da página, não só a aparência.

HTML5 trouxe tags semânticas — elas descrevem o papel de cada parte da página: <header> (cabeçalho), <nav> (menu de navegação), <main> (conteúdo principal), <section> (uma seção temática), <article> (conteúdo independente, como um post) e <footer> (rodapé).

semantica.html 
<header>
  <h1>Meu Blog</h1>
  <nav>
    <a href="#inicio">Início</a>
    <a href="#sobre">Sobre</a>
  </nav>
</header>

<main>
  <article>
    <h2>Meu primeiro post</h2>
    <p>Conteúdo do post aqui.</p>
  </article>
</main>

<footer>
  <p>&copy; 2026 Meu Blog</p>
</footer>
Dica: Você poderia fazer tudo isso com <div>, mas as tags semânticas comunicam significado tanto para outros programadores quanto para leitores de tela e buscadores.
Aprofundando: Buscadores como o Google usam as tags semânticas para entender melhor do que se trata a página, o que pode influenciar como ela aparece nos resultados de busca — é um dos primeiros passos de SEO (otimização para buscadores).

Mais um exemplo

secoes.html 
<main>
  <section>
    <h2>Sobre nós</h2>
    <p>Somos uma pequena empresa...</p>
  </section>
  <section>
    <h2>Nossos produtos</h2>
    <p>Confira o catálogo...</p>
  </section>
</main>

🧩 Desafio prático

  </article>

</footer>

Meta tags e SEO básico

Informações invisíveis que ajudam buscadores e redes sociais a entender sua página.

Tags <meta> ficam dentro do <head> e carregam informações sobre a página que não aparecem diretamente na tela — como uma descrição usada pelo Google nos resultados de busca, ou instruções para a página se adaptar a celulares.

meta_tags.html 
<head>
  <meta charset="UTF-8">
  <meta name="description" content="Curso gratuito de HTML para iniciantes.">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Curso de HTML</title>
</head>
Dica: A meta tag viewport é essencial para que a página fique bem ajustada em celulares — sem ela, o navegador mobile costuma exibir a página como se fosse um monitor grande, minúscula demais para ler.
Aprofundando: A meta name="description" normalmente é o texto que aparece embaixo do título do site nos resultados do Google — vale a pena escrevê-la pensando em atrair quem está pesquisando, com um resumo claro e direto.

Mais um exemplo

description_boa.html 
<!-- pouco útil -->
<meta name="description" content="Página inicial">

<!-- mais útil para SEO -->
<meta name="description" content="Aprenda Python do zero com exercícios práticos e um editor de código real.">

Acessibilidade básica

Fazendo páginas que funcionam para todo mundo, inclusive com leitores de tela.

Acessibilidade significa construir páginas que também funcionam bem para pessoas com deficiência — visual, motora, auditiva. Boa parte já vem naturalmente de usar HTML corretamente: alt em imagens, label em campos de formulário, e tags semânticas em vez de <div> para tudo.

acessibilidade.html 
<img src="grafico.png" alt="Gráfico de vendas do último trimestre">

<button aria-label="Fechar janela">✕</button>

<label for="busca">Buscar no site:</label>
<input type="search" id="busca">
Dica: O atributo aria-label dá um texto descritivo para leitores de tela quando o conteúdo visível (como um ícone) não é suficiente para explicar o que o elemento faz.
Aprofundando: Uma boa forma de testar acessibilidade é tentar navegar pela página só com o teclado (usando Tab para pular entre elementos) — se você não conseguir usar um botão ou link sem o mouse, provavelmente alguém que depende do teclado também não conseguirá.

Mais um exemplo

foco_teclado.html 
<!-- links e botões já são acessíveis por teclado por padrão -->
<a href="#conteudo">Pular para o conteúdo</a>
<button>Confirmar</button>

<!-- evite usar &lt;div&gt; como se fosse um botão sem trabalho extra de acessibilidade -->

Projeto final: página de perfil

Juntando estrutura, texto, listas, links e semântica em uma página completa.

Este projeto reúne quase tudo que você viu: uma estrutura semântica completa, uma imagem, uma lista de habilidades e links para redes sociais — o tipo de página "sobre mim" que muita gente cria como portfólio.

perfil.html 
<header>
  <h1>Ana Souza</h1>
  <p>Desenvolvedora front-end iniciante</p>
</header>

<main>
  <section>
    <h2>Sobre mim</h2>
    <p>Estou aprendendo <strong>HTML</strong> e me preparando para aprender CSS e JavaScript.</p>
  </section>

  <section>
    <h2>Habilidades</h2>
    <ul>
      <li>HTML</li>
      <li>Organização de conteúdo</li>

    </ul>
  </section>
</main>

  <a href="mailto:ana@exemplo.com">ana@exemplo.com</a>
</footer>
Desafio: Tente adicionar uma foto sua (ou um avatar) com <img> logo abaixo do <h1>, com um alt descritivo.
Aprofundando: Repare como a página usa header, main com duas section, e footer — a mesma estrutura semântica do capítulo anterior, só que preenchida com conteúdo real. É assim que a maioria dos sites profissionais organiza o HTML.

Para onde ir depois

Ideias de próximos passos para continuar praticando fora deste guia.

HTML por si só só cuida da estrutura — o próximo passo natural é aprender CSS para estilizar o que você construiu aqui, e depois JavaScript para adicionar interatividade. A boa notícia é que a base de tags que você aprendeu neste curso vai continuar sendo usada exatamente da mesma forma.

Dica: Valide seu HTML de vez em quando no validador oficial do W3C — ele aponta tags mal fechadas ou atributos incorretos que o navegador tolera, mas que idealmente deveriam ser corrigidos.
