Introdução ao JavaScript

A linguagem que dá vida e interatividade às páginas.

Enquanto HTML estrutura e CSS estiliza, JavaScript adiciona comportamento: reagir a cliques, validar formulários, atualizar a página sem recarregar. Ele roda direto no navegador de quem visita o site. A função console.log() é a ferramenta mais básica para "imprimir" valores e depurar o código.

primeiro_script.html 
<script>
  console.log("Olá, mundo!");
  console.log("Estou aprendendo JavaScript.");
</script>
Dica: Neste curso, console.log() aparece no painel de resultado abaixo do código — em um site real, ele normalmente aparece no console do navegador (acessível pelo F12).
Aprofundando: JavaScript também roda fora do navegador, no servidor, através do Node.js — mas neste curso vamos focar no uso mais comum para quem está começando: dentro de páginas HTML, rodando no navegador de quem acessa o site.

Mais um exemplo

onde_roda.html 
<script>
  console.log("Este código roda no navegador de quem abre a página.");
  console.log(typeof window);
</script>

01

Variáveis e tipos de dados

Guardando valores para usar depois.

Variáveis são declaradas com let (pode mudar depois) ou const (não pode ser reatribuída). O tipo de dado é detectado automaticamente: number, string, boolean, entre outros. Use typeof para descobrir o tipo de um valor.

variaveis.html 
<script>
  let nome = "Ana";
  let idade = 28;
  const PI = 3.14;
  let estaEstudando = true;

  console.log(nome, idade, PI, estaEstudando);
  console.log(typeof idade);
</script>
Dica: Prefira const por padrão, e só use let quando o valor realmente precisar mudar — isso deixa o código mais previsível e evita reatribuições acidentais.
Aprofundando: A antiga palavra-chave var ainda funciona em JavaScript, mas tem um comportamento de escopo mais confuso do que let e const — em código novo, é considerada ultrapassada.

Mais um exemplo

let_vs_var.html 
<script>
  let contador = 0;
  contador = contador + 1;
  console.log(contador);

  const nomeFixo = "Curso";
  // nomeFixo = "Outro"; // isso geraria erro, const não pode ser reatribuída
  console.log(nomeFixo);
</script>

02

Operadores

Fazendo contas, comparações e combinando condições.

Operadores aritméticos (+ - * /) funcionam como em uma calculadora. Operadores de comparação (=== !== > <) retornam true ou false. Prefira sempre === (igualdade estrita) em vez de ==, que pode converter tipos de forma inesperada.

operadores.html 
<script>
  let a = 10, b = 3;

  console.log(a + b);
  console.log(a % b);
  console.log(a > b);
  console.log(a === 10 && b === 3);
  console.log("5" == 5);
  console.log("5" === 5);
</script>
Cuidado: == converte tipos antes de comparar (por isso "5" == 5 dá true), enquanto === compara sem converter — quase sempre prefira ===.
Aprofundando: O operador ?? (nullish coalescing) devolve o valor da direita só quando o da esquerda é null ou undefined — muito útil para definir valores padrão de forma segura.

Mais um exemplo

operador_nullish.html 
<script>
  let apelido;
  let nomeExibido = apelido ?? "Visitante";
  console.log(nomeExibido);
</script>

03

Strings (texto)

Criando, juntando e formatando texto.

Template literals (com crases `) permitem inserir variáveis direto no texto usando ${variavel} — mais legível do que concatenar com +. Strings também têm métodos úteis como .toUpperCase(), .length e .slice().

strings.html 
<script>
  const nome = "Carlos";
  const pontos = 87;

  const mensagem = `${nome} fez ${pontos} pontos!`;
  console.log(mensagem);
  console.log(nome.toUpperCase());
  console.log(nome.length);
</script>
Dica: Template literals também suportam múltiplas linhas naturalmente, sem precisar de caracteres especiais de quebra de linha.
Aprofundando: O método .slice(inicio, fim) extrai parte de uma string, e .split(separador) transforma uma string em um array, dividindo pelo caractere indicado — muito usado para processar texto digitado por um usuário.

Mais um exemplo

slice_split.html 
<script>
  const frase = "javascript é divertido";
  console.log(frase.slice(0, 10));
  console.log(frase.split(" "));
</script>

04

Condicionais

Fazendo o programa tomar decisões com if, else if e else.

O bloco depois do if só roda se a condição entre parênteses for true. else if testa outra condição, e else cobre todos os outros casos. Para decisões simples de dois caminhos, o operador ternário condicao ? valorSeVerdadeiro : valorSeFalso é uma alternativa compacta.

condicionais.html 
<script>
  const nota = 7.5;

  if (nota >= 9) {
    console.log("Excelente");
  } else if (nota >= 6) {
    console.log("Aprovado");
  } else {
    console.log("Precisa estudar mais");
  }

  const status = nota >= 6 ? "aprovado" : "reprovado";
  console.log(status);
</script>
Dica: Em JavaScript, valores como 0, "" (string vazia), null e undefined são considerados "falsy" (tratados como falso) dentro de um if — todo o resto é "truthy".
Aprofundando: Para muitas condições possíveis para a mesma variável, um switch pode ser mais legível que vários else if encadeados — ele compara um valor contra vários casos possíveis.

Mais um exemplo

switch.html 
<script>
  const dia = "terca";

  switch (dia) {
    case "segunda":
      console.log("Início de semana");
      break;
    case "terca":
      console.log("Segundo dia");
      break;
    default:
      console.log("Outro dia");
  }
</script>

05

Laços de repetição

Repetindo uma ação várias vezes sem copiar e colar código.

O for clássico repete um número definido de vezes, controlando um contador. O while repete enquanto uma condição continuar verdadeira. break interrompe o laço, e continue pula para a próxima repetição.

loops.html 
<script>
  for (let i = 1; i <= 3; i++) {
    console.log(`Rodada ${i}`);
  }

  let contador = 0;
  while (contador < 3) {
    console.log("Ainda contando...");
    contador++;
  }
</script>
Cuidado: Se você esquecer de atualizar a variável de controle dentro de um while, o laço nunca termina — isso trava a página (loop infinito).
Aprofundando: Existe também o for...of, feito para percorrer os itens de um array de forma mais direta, sem precisar controlar um índice manualmente.

Mais um exemplo

for_of.html 
<script>
  const frutas = ["maçã", "banana", "uva"];

  for (const fruta of frutas) {
    console.log(fruta);
  }
</script>

06

Arrays (listas)

Guardando várias informações em uma única variável, em ordem.

Um array é criado com colchetes [ ] e guarda uma coleção ordenada de valores. Cada item tem uma posição (índice), começando em 0. Métodos como .push() (adiciona ao final) e .length (tamanho) são muito usados no dia a dia.

arrays.html 
<script>
  const frutas = ["maçã", "banana", "uva"];

  console.log(frutas[0]);
  frutas.push("pera");
  console.log(frutas);
  console.log(frutas.length);
</script>
Dica: Índices negativos não funcionam como em outras linguagens — para pegar o último item, use frutas[frutas.length - 1] ou o método .at(-1).
Aprofundando: Métodos como .sort() (ordena), .reverse() (inverte a ordem) e .includes() (verifica se um valor existe no array) resolvem tarefas comuns sem precisar escrever um laço manualmente.

Mais um exemplo

metodos_uteis.html 
<script>
  const numeros = [5, 2, 9, 1];

  console.log([...numeros].sort());
  console.log(numeros.includes(9));
  console.log(numeros.at(-1));
</script>

07

Objetos

Agrupando informações relacionadas com pares de chave e valor.

Um objeto agrupa dados relacionados usando chaves nomeadas: { nome: "Ana", idade: 28 }. Acesse valores com objeto.chave ou objeto["chave"]. Diferente de arrays, objetos não têm uma ordem numérica — a organização é por nome.

objetos.html 
<script>
  const pessoa = {
    nome: "Júlia",
    idade: 31,
    cidade: "São Paulo"
  };

  console.log(pessoa.nome);
  pessoa.idade = 32;
  console.log(pessoa);
</script>
Dica: Use Object.keys(objeto) para obter um array com todas as chaves, ou for (const chave in objeto) para percorrer todas elas em um laço.
Aprofundando: Objetos podem conter arrays, e arrays podem conter objetos — combinando os dois, é possível representar dados bem mais complexos, como uma lista de produtos, cada um com nome, preço e categoria.

Mais um exemplo

objetos_aninhados.html 
<script>
  const produtos = [
    { nome: "Caderno", preco: 15 },
    { nome: "Mochila", preco: 89 }
  ];

  for (const produto of produtos) {
    console.log(`${produto.nome}: R$ ${produto.preco}`);
  }
</script>

08

Funções

Empacotando um pedaço de código para reutilizar quando quiser.

Uma função é definida com function nome(parametros) { ... }, pode receber parâmetros e devolver um resultado com return. Funções evitam repetir o mesmo código várias vezes ao longo do programa.

funcoes.html 
<script>
  function calcularMedia(nota1, nota2) {
    return (nota1 + nota2) / 2;
  }

  const resultado = calcularMedia(8, 6);
  console.log(`Média: ${resultado}`);
</script>
Dica: Parâmetros podem ter valores padrão: function saudacao(nome = "visitante") — assim, chamar a função sem argumento nenhum ainda funciona.
Aprofundando: Sem um return explícito, uma função em JavaScript devolve undefined automaticamente — é importante lembrar disso ao usar o valor de retorno de uma função em outro lugar do código.

Mais um exemplo

parametro_padrao.html 
<script>
  function saudacao(nome = "visitante") {
    console.log(`Olá, ${nome}!`);
  }

  saudacao();
  saudacao("Marina");
</script>

09

Arrow functions

Uma forma mais compacta de escrever funções.

Arrow functions (=>) são uma sintaxe mais curta para escrever funções, muito usadas em callbacks: (parametros) => expressao. Quando o corpo é uma única expressão, o return pode ficar implícito.

arrow_functions.html 
<script>
  function somarTradicional(a, b) {
    return a + b;
  }

  const somar = (a, b) => a + b;

  console.log(somarTradicional(2, 3));
  console.log(somar(2, 3));
</script>
Dica: Quando a arrow function tem só um parâmetro, os parênteses são opcionais: nome => nome.toUpperCase() — mas muita gente prefere sempre usar parênteses por clareza.
Aprofundando: Arrow functions não criam seu próprio this — elas usam o this do contexto onde foram escritas. Isso costuma ser uma vantagem em callbacks dentro de objetos ou classes, evitando um problema comum com funções tradicionais.

Mais um exemplo

arrow_em_array.html 
<script>
  const numeros = [1, 2, 3, 4];
  const dobrados = numeros.map(n => n * 2);
  console.log(dobrados);
</script>

Selecionando e alterando elementos (DOM)

Fazendo o JavaScript enxergar e mudar a página.

O DOM (Document Object Model) é como o navegador representa a página para o JavaScript manipular. document.getElementById("id") busca um elemento pelo id, e propriedades como .textContent e .innerHTML mudam o conteúdo dele.

dom_basico.html 
<p id="mensagem">Texto original</p>

<script>
  const paragrafo = document.getElementById("mensagem");
  paragrafo.textContent = "Texto alterado pelo JavaScript!";
  paragrafo.style.color = "blue";
</script>
Dica: document.querySelector(".classe") é mais flexível que getElementById — ele aceita qualquer seletor CSS, incluindo classes, e retorna o primeiro elemento encontrado.
Aprofundando: Use .textContent quando quiser inserir só texto simples (mais seguro), e .innerHTML só quando realmente precisar inserir HTML — inserir texto de usuários direto com innerHTML pode abrir brechas de segurança em sites reais.

Mais um exemplo

query_selector.html 
<div class="caixa">Conteúdo original</div>

<script>
  const caixa = document.querySelector(".caixa");
  caixa.style.background = "yellow";
  caixa.style.padding = "10px";
</script>

11

Eventos (cliques e mais)

Fazendo a página reagir a ações da pessoa que está usando.

elemento.addEventListener("evento", funcao) registra uma ação para rodar quando o evento acontecer — "click" para cliques, "input" para digitação em campos, entre muitos outros. É assim que botões, formulários e menus interativos funcionam.

eventos.html 
<button id="botao">Clique aqui</button>
<p id="contador">Cliques: 0</p>

<script>
  let cliques = 0;
  const botao = document.getElementById("botao");
  const contador = document.getElementById("contador");

  botao.addEventListener("click", () => {
    cliques++;
    contador.textContent = `Cliques: ${cliques}`;
  });
</script>
Dica: O objeto de evento (geralmente chamado de e ou event) carrega informações sobre o que aconteceu — como e.target, que indica exatamente qual elemento disparou o evento.
Aprofundando: O evento "input" dispara a cada tecla digitada em um campo de texto, o que permite validar ou reagir ao conteúdo em tempo real, sem esperar o formulário ser enviado.

Mais um exemplo

evento_input.html 
<input id="campo" placeholder="Digite algo">
<p id="espelho"></p>

<script>
  const campo = document.getElementById("campo");
  const espelho = document.getElementById("espelho");

  campo.addEventListener("input", () => {
    espelho.textContent = `Você digitou: ${campo.value}`;
  });
</script>

12

Métodos de array: map, filter, reduce

Transformando listas de forma compacta, sem laços manuais.

.map() transforma cada item de um array e devolve um novo array; .filter() mantém só os itens que passam num teste; .reduce() combina todos os itens em um único valor (como uma soma). Os três recebem uma função como argumento.

map_filter.html 
<script>
  const numeros = [1, 2, 3, 4, 5];

  const dobrados = numeros.map(n => n * 2);
  const pares = numeros.filter(n => n % 2 === 0);
  const soma = numeros.reduce((total, n) => total + n, 0);

  console.log(dobrados);
  console.log(pares);
  console.log(soma);
</script>
Dica: Nenhum desses três métodos altera o array original — eles sempre devolvem um novo array (ou valor), o que ajuda a evitar bugs causados por mudanças inesperadas nos dados.
Aprofundando: Esses métodos podem ser encadeados: numeros.filter(...).map(...) aplica um filtro e depois transforma o resultado, tudo em uma linha só, sem variáveis intermediárias.

JSON

O formato de dados mais usado para trocar informações na web.

JSON (JavaScript Object Notation) é um formato de texto para representar dados, muito parecido com objetos e arrays de JavaScript. JSON.stringify(objeto) converte um objeto em texto JSON; JSON.parse(texto) faz o caminho inverso.

json.html 
<script>
  const pessoa = { nome: "Ana", idade: 28 };

  const texto = JSON.stringify(pessoa);
  console.log(texto);
  console.log(typeof texto);

  const objetoDeVolta = JSON.parse(texto);
  console.log(objetoDeVolta.nome);
</script>
Dica: JSON é o formato mais comum para APIs na web — quando seu código busca dados de um servidor, eles quase sempre chegam em formato JSON, precisando de JSON.parse() para virar um objeto usável.
Aprofundando: JSON.stringify(objeto, null, 2) formata o texto com indentação de 2 espaços, o que facilita muito a leitura ao inspecionar objetos grandes durante o desenvolvimento.

Mais um exemplo

json_formatado.html

Assincronismo básico (setTimeout e Promises)

Executando código que leva um tempo para terminar.

setTimeout(funcao, tempoEmMs) agenda uma função para rodar depois de um tempo, sem travar o resto do código. Operações mais complexas (como buscar dados de um servidor) costumam usar Promise, e a sintaxe async/await torna esse código mais fácil de ler.

settimeout.html 
<script>
  console.log("Início");

  setTimeout(() => {
    console.log("Isso aparece depois de 1 segundo");
  }, 1000);

  console.log("Fim (roda antes do setTimeout)");
</script>
Dica: Repare na ordem da saída: "Fim" aparece antes da mensagem do setTimeout, mesmo estando depois no código — isso acontece porque JavaScript não trava esperando o tempo passar.
Aprofundando: async function combinada com await permite escrever código assíncrono como se fosse sequencial, o que fica bem mais fácil de ler do que encadear vários .then().

Mais um exemplo

async_await.html 
<script>
  function esperar(ms) {
    return new Promise(resolve => setTimeout(resolve, ms));
  }

  async function exemplo() {
    console.log("Começando...");
    await esperar(1000);
    console.log("1 segundo se passou!");
  }

  exemplo();
</script>

Tratando erros (try/catch)

Evitar que o programa quebre quando algo dá errado.

O bloco try { ... } catch (erro) { ... } permite "tentar" um código arriscado e capturar o erro caso ele aconteça, em vez de travar o script inteiro. O objeto erro geralmente tem uma propriedade .message com a descrição do problema.

try_catch.html 
<script>
  function dividir(a, b) {
    if (b === 0) {
      throw new Error("Não é possível dividir por zero");
    }
    return a / b;
  }

  try {
    console.log(dividir(10, 0));
  } catch (erro) {
    console.log("Erro capturado:", erro.message);
  }
</script>
Dica: throw new Error("mensagem") cria e "lança" um erro manualmente — muito usado para validar dados e avisar quando algo não está certo, de forma controlada.
Aprofundando: Um bloco finally { ... } pode ser adicionado depois do catch, e sempre executa, tendo dado erro ou não — muito usado para "limpeza", como esconder um indicador de carregamento.

Mais um exemplo

finally.html 
<script>
  try {
    console.log("Tentando...");
    throw new Error("Algo deu errado");
  } catch (erro) {
    console.log("Capturado:", erro.message);
  } finally {
    console.log("Isso sempre roda, com erro ou sem erro");
  }
</script>

Projeto final: lista de tarefas interativa

Juntando DOM, eventos e arrays em uma pequena aplicação de verdade.

Este projeto combina quase tudo do curso: um array guarda as tarefas, funções organizam as ações, e eventos conectam a interface (botão, campo de texto) com a lógica — o mesmo padrão usado em aplicações web reais, só que em escala bem menor.

lista_tarefas.html 
<input id="novaTarefa" placeholder="Nova tarefa">
<button id="btnAdicionar">Adicionar</button>
<ul id="listaTarefas"></ul>

<script>
  const tarefas = [];
  const campo = document.getElementById("novaTarefa");
  const lista = document.getElementById("listaTarefas");

  function renderizar() {
    lista.innerHTML = "";
    for (const tarefa of tarefas) {
      const item = document.createElement("li");
      item.textContent = tarefa;
      lista.appendChild(item);
    }
  }

  document.getElementById("btnAdicionar").addEventListener("click", () => {
    if (campo.value.trim() !== "") {
      tarefas.push(campo.value);
      campo.value = "";
      renderizar();
    }
  });
</script>
Desafio: Tente adicionar um botão "Limpar tudo" que esvazia o array tarefas (tarefas.length = 0) e chama renderizar() de novo.
Aprofundando: Repare que renderizar() é chamada toda vez que os dados mudam — em vez de manipular a lista na tela diretamente ao adicionar uma tarefa, o código sempre reconstrói a lista inteira a partir do array. Esse padrão (dados mudam → tela é redesenhada) é a base de frameworks modernos como React.

Mais um exemplo

remover_tarefa.html 
<script>
  function removerTarefa(indice) {
    tarefas.splice(indice, 1);
    renderizar();
  }
  // dica: dentro de renderizar(), um botão "remover" em cada
  // item poderia chamar removerTarefa(indice) ao ser clicado.
</script>
