O que é Python

Uma linguagem de programação criada para ser lida quase como português ou inglês simples.

Python foi criada por Guido van Rossum em 1991. Ela é usada para automatizar tarefas, analisar dados, construir sites, treinar modelos de inteligência artificial e muito mais. O motivo de tanta gente começar por Python é simples: a sintaxe é enxuta, sem chaves { } ou ponto e vírgula ; no fim de cada linha — os blocos de código são organizados por indentação (espaços no início da linha).

meu_primeiro_programa.py 
print("Olá, mundo!")
print("Estou aprendendo Python.")
SAÍDAOlá, mundo! Estou aprendendo Python.
Dica: a função print() mostra algo na tela. É a primeira ferramenta que todo programador Python usa.
Aprofundando: Quando você roda um arquivo .py, o Python lê o código de cima para baixo, linha por linha, e executa cada instrução na ordem em que aparece — por isso a ordem das linhas importa.

Mais um exemplo

mais_prints.py 
nome = "Mundo"
print("Olá,", nome, "!")
print("Isso é uma", "frase", "montada", "com", "várias", "partes")
print(1, 2, 3, sep=" - ")

Uma variável é um nome que guarda um valor para você usar depois.

Em Python você não precisa declarar o tipo da variável — ela descobre sozinha. Os tipos mais comuns são:

Operadores

Símbolos que fazem contas, comparações e combinam condições.

Os operadores aritméticos (+ - * /) funcionam como em uma calculadora. Já os operadores de comparação (== != > <) sempre retornam True ou False.

operadores.py 
a = 10
b = 3

print(a + b)    # soma -> 13
print(a // b)   # divisão inteira -> 3
print(a % b)    # resto -> 1
print(a > b)    # comparação -> True
print(a == 10 and b == 3)  # -> True
SAÍDA13 3 1 True True
Aprofundando: Assim como na matemática, Python segue uma ordem de precedência entre operadores: multiplicação e divisão acontecem antes de soma e subtração. Use parênteses ( ) sempre que quiser deixar a ordem explícita e evitar erros de leitura.

Mais um exemplo

precedencia.py 
resultado1 = 2 + 3 * 4
resultado2 = (2 + 3) * 4

print(resultado1)
print(resultado2)
print(10 - 2 ** 2)

Texto (strings)

Como criar, juntar e formatar texto.

A forma mais prática de montar textos com variáveis dentro é usando f-strings: coloque um f antes das aspas e escreva a variável entre chaves.

strings.py 
nome = "Carlos"
pontos = 87

mensagem = f"{nome} fez {pontos} pontos!"
print(mensagem)
print(nome.upper())
print(len(nome))
SAÍDACarlos fez 87 pontos! CARLOS 6
Dica: len() conta quantos caracteres tem o texto — muito útil para validar formulários e entradas de usuário.
Aprofundando: Strings em Python podem ser "fatiadas" com colchetes, como listas: texto[0:3] pega os três primeiros caracteres. Isso é chamado de slicing e funciona porque, por baixo dos panos, uma string é uma sequência ordenada de caracteres.

Mais um exemplo

fatiando_texto.py 
palavra = "programacao"

print(palavra[0:4])
print(palavra[-4:])
print(palavra[::-1])
print(palavra.replace("a", "@"))

Condicionais

Fazer o programa tomar decisões com if, elif e else.

O bloco depois do if só roda se a condição for verdadeira. Repare que a linha seguinte é indentada — é assim que Python sabe o que pertence a cada bloco.

condicionais.py 
nota = 7.5

if nota >= 9:
    print("Excelente")
elif nota >= 6:
    print("Aprovado")
else:
    print("Precisa estudar mais")
SAÍDAAprovado
Aprofundando: É possível combinar várias condições usando and (todas precisam ser verdadeiras) e or (basta uma ser verdadeira). Condicionais também podem ficar "aninhadas", ou seja, um if dentro de outro if.

Mais um exemplo

idade = 20

else:
    print("Não pode dirigir")

Laços de repetição

Repetir uma ação várias vezes sem copiar e colar código.

O for percorre um conjunto de itens (uma lista, um intervalo de números, um texto). O while repete enquanto uma condição continuar verdadeira.

loops.py 
for numero in range(1, 4):
    print(f"Rodada {numero}")

contador = 0
while contador < 3:
    print("Ainda contando...")
    contador += 1
SAÍDARodada 1 Rodada 2 Rodada 3 Ainda contando... Ainda contando... Ainda contando...
Cuidado: se você esquecer de aumentar o contador dentro do while, o laço nunca termina — isso se chama loop infinito.
Aprofundando: Dentro de um laço, break interrompe a repetição imediatamente, e continue pula para a próxima repetição sem executar o restante do bloco. São ótimos para casos como "pare de procurar assim que encontrar" ou "ignore os itens inválidos".

Mais um exemplo

break_continue.py 
for numero in range(1, 10):
    if numero == 5:
        break
    print(numero)

print("---")

for numero in range(1, 6):
    if numero % 2 == 0:
        continue
    print(numero)
🧩 Desafio prático

Listas

Uma coleção ordenada de valores, que pode crescer ou encolher.

Listas são criadas com colchetes [ ]. Cada item tem uma posição (índice), começando em 0.

listas.py 
frutas = ["maçã", "banana", "uva"]

print(frutas[0])       # primeiro item
frutas.append("pera")  # adiciona no final
print(frutas)

for fruta in frutas:
    print(f"- {fruta}")
SAÍDAmaçã ['maçã', 'banana', 'uva', 'pera'] - maçã - banana - uva - pera
Aprofundando: Listas também aceitam slicing, igual às strings — lista[1:3] pega uma "fatia" da lista. E funções como sorted(), max() e min() facilitam tarefas comuns sem precisar escrever um laço manualmente.

Mais um exemplo

mais_listas.py 
numeros = [5, 2, 9, 1, 7]

print(sorted(numeros))
print(max(numeros))
print(min(numeros))
print(numeros[1:3])
print(sum(numeros) / len(numeros))

Dicionários

Pares de chave e valor — ótimo para representar um registro de dados.

Ao contrário das listas, que usam posição, dicionários usam uma chave (geralmente texto) para buscar um valor.

dicionarios.py 
pessoa = {
    "nome": "Júlia",
    "idade": 31,
    "cidade": "São Paulo"
}

print(pessoa["nome"])
pessoa["idade"] = 32   # atualiza o valor
print(pessoa)
SAÍDAJúlia {'nome': 'Júlia', 'idade': 32, 'cidade': 'São Paulo'}
Aprofundando: O método .items() permite percorrer um dicionário obtendo a chave e o valor ao mesmo tempo em um laço for. Já .get("chave") busca um valor sem gerar erro caso a chave não exista.

Mais um exemplo

percorrendo_dict.py 
precos = {"maçã": 3.5, "banana": 2.0, "uva": 8.9}

for fruta, preco in precos.items():
    print(f"{fruta}: R$ {preco}")

print(precos.get("pera", "não encontrado"))

List comprehensions

Uma forma compacta de criar listas a partir de outras listas.

Em vez de escrever um for de várias linhas para transformar uma lista, você pode fazer isso em uma linha só. É uma das marcas registradas de um código Python "pythônico".

comprehensions.py 
numeros = [1, 2, 3, 4, 5]

# jeito tradicional
dobrados = []
for n in numeros:
    dobrados.append(n * 2)

# com list comprehension
dobrados = [n * 2 for n in numeros]
pares = [n for n in numeros if n % 2 == 0]

print(dobrados)
print(pares)
SAÍDA[2, 4, 6, 8, 10] [2, 4]
Dica: se a linha ficar difícil de ler, volte para o for tradicional — clareza sempre vence esperteza.
Aprofundando: Também existem dict comprehensions, que criam dicionários da mesma forma compacta: {chave: valor for item in lista}. O princípio é o mesmo das list comprehensions, só muda o tipo de coleção criada.

Mais um exemplo

dict_comprehension.py 
numeros = [1, 2, 3, 4, 5]

quadrados = {n: n ** 2 for n in numeros}
print(quadrados)

maiusculas = [p.upper() for p in ["python", "código", "dados"]]
print(maiusculas)
🧩 Desafio prático

Funções

Empacotar um pedaço de código para reutilizar quando quiser.

Uma função é definida com def, pode receber parâmetros e devolver um resultado com return.

funcoes.py 
def calcular_media(nota1, nota2):
    media = (nota1 + nota2) / 2
    return media

resultado = calcular_media(8, 6)

SAÍDAMédia: 7.0
Dica: dê nomes de função que descrevam a ação, como calcular_media — isso torna o código autoexplicativo.
Aprofundando: Parâmetros podem ter valores padrão (def saudacao(nome="visitante")), o que os torna opcionais na hora de chamar a função. E *args permite que uma função receba uma quantidade variável de argumentos.

Mais um exemplo

def saudacao(nome="visitante"):
    print(f"Olá, {nome}!")

saudacao()
saudacao("Marina")

def somar_tudo(*numeros):

Tratando erros

Evitar que o programa quebre quando algo dá errado.

O bloco try/except permite "tentar" um código arriscado e capturar o erro (exceção) caso ele aconteça, em vez de derrubar o programa inteiro.

erros.py 
try:
    idade = int(input("Digite sua idade: "))
    print(f"Você tem {idade} anos")
except ValueError:
    print("Isso não parece um número válido.")
SAÍDA (se digitar "abc")Isso não parece um número válido.
Aprofundando: É possível capturar mais de um tipo de erro com blocos except separados, e usar finally para um trecho que sempre executa, dando erro ou não — muito usado para liberar recursos, como fechar um arquivo.

Mais um exemplo

varios_except.py 
def dividir(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        print("Não é possível dividir por zero")
    except TypeError:
        print("Os valores precisam ser números")
    finally:
        print("Tentativa de divisão finalizada")

dividir(10, 0)
dividir(10, "a")

Classes e objetos

Modelar coisas do mundo real como código, com dados e comportamento juntos.

Uma classe é um molde. Um objeto é algo criado a partir desse molde. O método especial __init__ roda automaticamente quando um objeto é criado.

classes.py 
class Cachorro:
    def __init__(self, nome, raca):
        self.nome = nome
        self.raca = raca

    def latir(self):
        print(f"{self.nome} diz: Au au!")

meu_cachorro = Cachorro("Bolinha", "Vira-lata")
meu_cachorro.latir()
SAÍDABolinha diz: Au au!
Aprofundando: Uma classe pode herdar de outra usando class Filha(Mae):, reaproveitando atributos e métodos e podendo adicionar ou sobrescrever comportamentos — essa é a ideia de herança, um dos pilares da programação orientada a objetos.

Mais um exemplo

heranca.py 
class Animal:
    def __init__(self, nome):
        self.nome = nome

    def emitir_som(self):
        print(f"{self.nome} faz um som")

class Gato(Animal):
    def emitir_som(self):
        print(f"{self.nome} diz: Miau!")

Animal("Bicho").emitir_som()
Gato("Whiskas").emitir_som()

Arquivos

Ler e salvar informações em arquivos de texto, para que os dados sobrevivam ao fim do programa.

O comando with open(...) abre um arquivo e garante que ele será fechado automaticamente, mesmo se algo der errado.

arquivos.py 
# escrever em um arquivo
with open("notas.txt", "w") as arquivo:
    arquivo.write("Estudar Python\n")
    arquivo.write("Fazer exercícios\n")

# ler o arquivo
with open("notas.txt", "r") as arquivo:
    conteudo = arquivo.read()
    print(conteudo)

Cuidado: o modo "w" apaga o conteúdo anterior do arquivo. Para adicionar sem apagar, use o modo "a" (append).

Boas práticas

Escrever código que outras pessoas — e você mesmo, no futuro — conseguem entender.

  • PEP 8 é o guia de estilo oficial de Python: nomes de variáveis em snake_case, indentação de 4 espaços, linhas curtas.
  • Use ambientes virtuais (python -m venv venv) para isolar as bibliotecas de cada projeto e evitar conflitos.
  • Escreva docstrings nas funções explicando o que elas fazem, não como fazem.
  • Prefira nomes descritivos: calcular_total é melhor que calc ou x.
boas_praticas.py 
def calcular_total_carrinho(precos):
    """Soma o preço de todos os itens do carrinho."""
    return sum(precos)

carrinho = [29.90, 15.50, 8.00]
print(calcular_total_carrinho(carrinho))
SAÍDA53.4
Aprofundando: Ferramentas como black (formatador automático) e flake8 (linter) ajudam a manter o código dentro do padrão PEP 8 sem esforço manual — muito usadas em times profissionais para manter um estilo consistente entre todos.

Mais um exemplo

nomes_descritivos.py 
# ruim: nomes genéricos, sem explicação
def calc(x, y):
    return x * y * 0.1

# melhor: nomes descritivos e uma docstring
def calcular_comissao(valor_venda, taxa=0.1):
    """Calcula a comissão de uma venda com base numa taxa."""
    return valor_venda * taxa

print(calcular_comissao(1000))

Projeto final: lista de tarefas

Juntando listas, funções e loops em um programa pequeno e completo.

Este exemplo combina quase tudo que você viu: uma lista guarda as tarefas, funções organizam as ações, e um laço mantém o programa rodando.

lista_de_tarefas.py 
tarefas = []

def adicionar(tarefa):
    tarefas.append(tarefa)
    print(f"'{tarefa}' adicionada.")

def listar():
    if not tarefas:
        print("Nenhuma tarefa ainda.")
        return
    for i, tarefa in enumerate(tarefas, 1):
        print(f"{i}. {tarefa}")

adicionar("Estudar Python")
adicionar("Fazer exercícios")
listar()

tarefas = []

def adicionar(tarefa):
    tarefas.append(tarefa)
    print(f"'{tarefa}' adicionada.")

def remover(tarefa):
    if tarefa in tarefas:
        tarefas.remove(tarefa)
        print(f"'{tarefa}' removida.")
    else:
        print(f"'{tarefa}' não encontrada.")
